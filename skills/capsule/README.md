# Capsule

Package knowledge, patterns or a whole skill into one markdown file another agent can load and act on. Sizes itself, never grows longer than its source, and names anything it leaves out.

## Use

```
/capsule [what to capture] | load <path>
```

## Requirements

None.

## Install

Copy this folder into your agent's skills directory (for example `~/.claude/skills/capsule` or `~/.agents/skills/capsule`). `SKILL.md` is the skill; `agents/openai.yaml` carries the Codex display name and invocation policy.
