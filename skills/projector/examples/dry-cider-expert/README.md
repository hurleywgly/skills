# Dry Cider Expert — Claude Project Package

A Claude Project for home cider makers in the Pacific Northwest, specializing in dry cider production.

## What This Is

A complete Project package you can upload to Claude (or ChatGPT) to create an expert cider-making assistant. The assistant combines:

- **Fermentation science** — Chemistry, yeast selection, achieving true dryness
- **Regional expertise** — Seattle-area orchards, harvest timing, local shops
- **Practical guidance** — Equipment costs, step-by-step processes, troubleshooting

## Setup Instructions

### For Claude Projects

1. Go to [claude.ai](https://claude.ai) and create a new Project
2. Copy the contents of `system_prompt.md` into the Project Instructions field
3. Upload all files from the `knowledge/` folder as Project Knowledge
4. Start chatting with your cider expert

### For ChatGPT

1. Go to [chatgpt.com](https://chatgpt.com) and create a new GPT or use Custom Instructions
2. Use `system_prompt.md` content as the system prompt/instructions
3. Upload knowledge files to the GPT's knowledge base
4. Configure and save
