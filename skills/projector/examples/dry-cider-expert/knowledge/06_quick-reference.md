# Quick Reference Guide

## Fermentation Temperature Ranges

| Yeast Type | Optimal Range | Acceptable | Avoid |
|------------|---------------|------------|-------|
| Cider-specific (Safcider, WLP775) | 55-65°F | 50-70°F | Below 50°F, above 75°F |
| Champagne (EC-1118) | 55-75°F | 50-86°F | Below 50°F |
| For best dry cider | **55-62°F** | — | Warm = fusel alcohols |

## Sugar & Alcohol Conversions

### Brix to ABV (Fully Fermented)

| Starting Brix | Approximate ABV |
|---------------|-----------------|
| 10% | 6.0% |
| 11% | 6.6% |
| 12% | 7.2% |
| 13% | 7.8% |
| 14% | 8.4% |

**Rule**: 1% Brix ≈ 0.6% ABV

### Gravity to ABV

**Formula**: (OG - FG) × 131.25 = ABV%

| Starting Gravity | Typical FG | ABV |
|------------------|------------|-----|
| 1.045 | 0.998 | 6.2% |
| 1.050 | 0.998 | 6.8% |
| 1.055 | 0.998 | 7.5% |
| 1.060 | 0.998 | 8.1% |

## Sulfite Dosing

| Stage | Dosage (ppm) | Campden Tablets | K-Meta Powder |
|-------|--------------|-----------------|---------------|
| Fresh juice | 50-100 | 1 tablet/gallon | 1/4 tsp/5 gal |
| At racking | 30-50 | 1/2 tablet/gallon | 1/8 tsp/5 gal |
| At bottling | 30-50 | 1/2 tablet/gallon | 1/8 tsp/5 gal |

**Maximum total**: 200 ppm (legal limit)
**Typical home cider**: 80-150 ppm total

## Off-Flavor Diagnosis

| Flavor | Cause | Fix |
|--------|-------|-----|
| **Vinegar/acetic** | Acetobacter (oxygen exposure) | Prevention only; add sulfite, use airlocks |
| **Hot/solvent** | Fusel alcohols (fermented too warm) | Age 6+ months; may mellow |
| **Rotten egg/sulfur** | Yeast stress | Splash-rack to aerate; usually dissipates |
| **Sherry/cardboard** | Oxidation | Prevention only; minimize headspace, add sulfite |
| **Mousy/musty** | Lactobacillus contamination | Usually unrecoverable |
| **Green apple** | Acetaldehyde (incomplete fermentation) | Let fermentation finish; age longer |
| **Harsh/astringent** | Excess tannins or young cider | Age 6-12 months; will soften |

## Timeline: First Batch

| Week | Activity |
|------|----------|
| **Week 1** | Day 1: Sanitize, add juice to fermenter |
| | Day 2: Pitch yeast (or Day 1 if no sulfite) |
| | Days 3-7: Observe bubbling, don't disturb |
| **Week 2-3** | Monitor gravity daily once bubbling slows |
| | Confirm stable gravity (3 days same reading) |
| **Week 3-4** | First rack to secondary vessel |
| | Add sulfite (30-50 ppm) |
| **Month 2-3** | Taste monthly, rack if sediment heavy |
| **Month 3-6** | Continue aging in secondary |
| | Plan bottling when satisfied with flavor |
| **Month 6** | Bottle (add priming sugar if carbonating) |
| | If bottle conditioning: 2-3 weeks at room temp |
| **Month 7+** | Drink and enjoy! |

## Cheat Sheet: Dry Cider Targets

| Parameter | Target | Range |
|-----------|--------|-------|
| Starting Brix | 11-12% | 10-14% |
| Final gravity | 0.995-0.998 | Below 1.000 |
| Residual sugar | <0.5% | Undetectable sweetness |
| ABV | 6.5-7.5% | 5.5-8.5% |
| Fermentation temp | 58-62°F | 55-65°F |
| Acid | 0.4-0.6% | Bright but not sharp |
| Tannin | 0.1-0.2% | Structure without harshness |

## Emergency Troubleshooting

### Fermentation Won't Start (48+ hours, no bubbles)

1. Check temperature—warm to 65-70°F
2. Verify no sorbate in juice (check ingredients)
3. Ensure yeast is fresh (check date)
4. Pitch new yeast if still no activity after 72 hours

### Fermentation Stuck (Gravity stopped above 1.000)

1. Warm to 65-70°F, wait 48 hours
2. Add yeast nutrient (1/4 tsp per gallon)
3. Gently swirl to resuspend yeast
4. If still stuck: pitch fresh yeast

### Cider Smells Like Sulfur

1. Don't panic—common during fermentation
2. Splash-rack: transfer with some aeration
3. Usually dissipates within 2-4 weeks
4. If persistent after 2 months: copper can help (advanced technique)

### Cider Won't Clear

1. Patience—most cider clears with time (2-6 months)
2. Cold crash: move to 35-40°F for 1-2 weeks
3. Use fining agent: pectic enzyme (if pectin haze) or bentonite (if protein haze)

### Bottles Not Carbonating

1. Verify yeast is still viable (did you add sorbate? pasteurize?)
2. Check temperature—needs 65-75°F for conditioning
3. Wait full 3 weeks before judging
4. Add a few grains of fresh yeast to each bottle (last resort)
