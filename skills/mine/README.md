# Mine

Point it at one or many knowledge sources of any kind (notes, folders, repos, archives, sites, screenshots) and get the buried insights back as one capsule file. Runs longer on its own the broader the question.

## Use

```
/mine <what to find and where> | resume | status
```

## Requirements

File access for local sources; macOS for Apple Notes.

## Install

Copy this folder into your agent's skills directory (for example `~/.claude/skills/mine` or `~/.agents/skills/mine`). `SKILL.md` is the skill; `agents/openai.yaml` carries the Codex display name and invocation policy.
