# JS Art

Original wall art drawn entirely in JavaScript on a canvas, made to look hand-made with physical media. Pick a direction from a researched library, react to a drawn gallery of concepts, then render the pick at 4K.

## Use

```
/js-art [look, mood, or pasted prompt] [where it will hang]
```

## Requirements

`python3` (standard library) and a browser.

## Install

Copy this folder into your agent's skills directory (for example `~/.claude/skills/js-art` or `~/.agents/skills/js-art`). `SKILL.md` is the skill; `agents/openai.yaml` carries the Codex display name and invocation policy.
