# API Client Switching Triggers

## Research Question
Why do developers leave their current API testing tools, and what's the breaking point that triggers the switch?

## Scope
**In bounds:** Pain points with existing tools (Postman, Insomnia, Thunder Client), switching triggers, emotional frustrations, workflow bottlenecks, pricing complaints
**Out of bounds:** Feature wishlists, detailed pricing analysis, market sizing, enterprise-only workflows

- **Time per cycle:** 3-5 minutes
- **Max cycles:** 10
- **Stop condition:** 3 consecutive cycles with <2 new insights

## Quality Signal
Each finding scored on 3-point rubric:
- **Actionable** (0/1): Can we build something in response?
- **Evidenced** (0/1): Backed by real user voice, not speculation?
- **Novel** (0/1): Something we didn't already know?

Score >= 2 = KEEP. Score < 2 = DISCARD.
