# Research

Persona-driven web research in scored cycles. It opens by asking what you want out of the research, keeps every cycle anchored to that, and ends with a synthesis reviewed from several perspectives.

## Use

```
/research run <brief-path> [--once|--autonomous] | new | persona [domain] | synthesize <slug> | status <slug> | list
```

## Requirements

Web search and page-fetch tools. Sub-agents are used when available.

## Install

Copy this folder into your agent's skills directory (for example `~/.claude/skills/research` or `~/.agents/skills/research`). `SKILL.md` is the skill; `agents/openai.yaml` carries the Codex display name and invocation policy.
