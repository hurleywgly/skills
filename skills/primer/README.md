# Primer

A self-learning tool: turn something hard to grasp into a TLDR / ELI5 visual explainer with one short animation, for yourself, a team or a family. Stays a local file unless you ask to publish it.

## Use

```
/primer <url(s), pasted source, or the thing to explain> [audience or angle]
```

## Requirements

Web search and page-fetch tools. Optional: the `vercel` CLI, only if you ask for a public link.

## Install

Copy this folder into your agent's skills directory (for example `~/.claude/skills/primer` or `~/.agents/skills/primer`). `SKILL.md` is the skill; `agents/openai.yaml` carries the Codex display name and invocation policy.
