# Think

Harden an idea before it becomes a plan: frame it working backwards from the outcome, run four fixed perspectives over the gaps, challenge the strongest assumption, then answer focused one-at-a-time questions.

## Use

```
/think <idea|plan|file> [--depth=quick|normal|deep] [--questions=N] [--manifest]
```

## Requirements

None.

## Install

Copy this folder into your agent's skills directory (for example `~/.claude/skills/think` or `~/.agents/skills/think`). `SKILL.md` is the skill; `agents/openai.yaml` carries the Codex display name and invocation policy.
