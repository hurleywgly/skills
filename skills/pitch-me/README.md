# Pitch Me

Get N genuinely different concepts on a brief before committing to one. Each is researched, gets an outside take, is shown in the medium that sells it, and the set comes back ranked with reasons, not scores.

## Use

```
/pitch-me <brief> [--count=9] [--medium=auto|diagram|wireframe|graphic|video] [--screenshots] [--converge] [--no-outside-take]
```

## Requirements

Optional: a second-opinion skill (`codex` or `claude`) for the outside take, and `ink` for the output page.

## Install

Copy this folder into your agent's skills directory (for example `~/.claude/skills/pitch-me` or `~/.agents/skills/pitch-me`). `SKILL.md` is the skill; `agents/openai.yaml` carries the Codex display name and invocation policy.
